# LegalMind AI — API & Database Reference

This document serves as the comprehensive technical reference for all **REST API endpoints** and **MongoDB data models** implemented across LegalMind AI.

---

## PART 1: DATABASE ARCHITECTURE & DATA MODELS

### Overview
- **Database Engine:** MongoDB 7.0 Community Edition running in Docker container `legalmind_mongodb` on host port `27018` (internal `27017`).
- **Object Data Modeling (ODM):** Mongoose 8.0.0 (Node.js/Express backend).
- **Authentication:** Scram-SHA-256 with root administrator credentials configured via environment variables.
- **Tenant Isolation Policy:** All user documents and associated records are strictly partitioned by `userId: mongoose.Schema.Types.ObjectId` referencing `User`. Cross-tenant queries are blocked at both query-level and middleware-level.

  - `{ email: 1 }` (Unique, auto-generated by Mongoose schema)

- **Key Methods:** `comparePassword(candidate)`, `toPublicJSON()` (strips password hash).
- **CRUD Accessors:** `auth.service.js`, `admin.controller.js`, `auth.middleware.js`.
