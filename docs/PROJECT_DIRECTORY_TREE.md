# LegalMind AI — Complete Project Directory Tree

This document provides a complete, granular, and accurate directory tree of the **LegalMindAI** codebase as discovered on the local filesystem.

---

## Exclusion & Inspection Policy

To maintain repository clarity and portability, the following directory categories are excluded from full file-by-file tree expansion, though their role and contents are documented below:
- **`node_modules/`** (`frontend/node_modules`, `backend/node-server/node_modules`): Third-party JavaScript dependencies managed by `npm`.
- **`venv/`** (`ai-service/venv`): Python 3.10 virtual environment containing installed packages (PyMuPDF, FastAPI, PyTorch, LangGraph, etc.).
- **`dist/`** (`frontend/dist`): Compiled production bundles generated by `vite build`.
- **`storage/`** (`storage/*`): Dynamic runtime storage directory for uploaded user contracts (PDF, DOCX, TXT) partitioned by `userId`.
- **`reports/`** (`reports/*.pdf`): Generated dynamic binary PDF audit dossiers.
- **`faiss_indexes/`** (`faiss_indexes/*.index`, `*.json`): Generated local vector indices and chunk metadata.
- **`.git/`**: Git version control metadata.
